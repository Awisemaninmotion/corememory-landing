How It Works

One index file. Zero infrastructure. Self-maintaining.

1

Index

A single INDEX.md maps your entire knowledge base — folder structure, file locations, what's where. ~200 tokens to read.

2

Route

The agent reads the index first, then pulls only the specific file it needs. No blind scanning.

3

Audit

A scheduled check re-verifies the index. New files, moved folders, stale entries — caught automatically.
